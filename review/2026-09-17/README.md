## Numerical boundaries

[numerical-probe/src/main.rs](numerical-probe/src/main.rs) calls only the public
rump and entropy APIs. It includes beta symmetry, central/tiny gamma, upper finite
log-gamma, eighteen Student quantiles and a crafted dense-normal endpoint.
`numerical-refresh.log` is the measured output. The entropy normal endpoint uses
sixteen zero u64s, then 1<<14, then zero; it yields the smallest positive f64 and
normal() returns negative infinity after halving that probability to zero.

Run against the recorded sibling combination:

```sh
cargo run --offline --locked --release --manifest-path review/2026-09-17/numerical-probe/Cargo.toml
```

`numeric-reference-R.log` was generated by public R math APIs:

```r
for (a in c(1e8, 1e10, 1e12, 1e14))
  cat(sprintf("%.0e,%.17g\n", a, pgamma(a, shape=a, lower.tail=FALSE)))
for (df in c(1, 2, 5, 10, 100, 10000))
  for (p in c(.75, .975, .999999))
    cat(sprintf("student,%g,%g,%.17g\n", df, p, qt(p, df)))
```

The beta oracle is exact symmetry. The gamma reference is also checked against
the DLMF large-a central expansion; the Student comparison is a sampled numerical
reference, not an error proof. The largest relative Student discrepancy is
4.656612873077393e-10.
